# ALIVO OS Command Center UI

This directory contains the approved desktop-first ALIVO OS command-center interface.

## Preview

Open `index.html` in a modern browser.

The layout is optimized for a 15-inch laptop display and scales down for tablet and mobile monitoring.

## Current scope

- Professional black and dark-red visual system
- Persistent navigation
- CEO command-center header
- ALIVO OS background identity
- KPI overview
- Agent activity
- Pending decisions
- System activity
- Scheduled content
- Alerts
- Business performance

The data is currently representative UI data. Backend connections will be added only when authorized by the active ALIVO-OS specification.
