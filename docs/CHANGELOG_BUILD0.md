# Build 0 Changelog

## Governance baseline

### Added

- The complete Build 0 governance and certification document set.
- A living requirements-to-evidence traceability matrix and knowledge graph.
- An offline, dependency-free audit with a stable `make audit` entry point.
- An integrity guard for the frozen Specification v1.0.

### Decisions

- Product scaffolding is intentionally excluded until architecture details are authorized.
- Certifications cover repository-foundation completeness, not unspecified product capability.

### Compatibility

- No public product interface exists, so no interface was changed.
