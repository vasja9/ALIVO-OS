# ALIVO-OS Architecture

> Status: Frozen for Build Phase

## Overview

ALIVO-OS is organized around a stable kernel with surrounding modules, services, UI, storage, integrations, and AI capabilities.

## Top-Level Areas

- `kernel/`: foundational coordination and authority boundaries.
- `modules/`: business capability modules.
- `services/`: runtime services and service interfaces.
- `ui/`: user-facing interface layer.
- `tests/`: validation assets and test scaffolding.

## Architectural Constraint

Architecture updates during Build Phase must remain consistent with Specification v1.0 and the ALIVO-OS Constitution.
