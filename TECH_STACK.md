# ALIVO-OS Technology Stack

## Version

Personal Operating System V1.0

## Status

Approved and frozen for Version 1.0.

## Approved Stack

| Area | Technology |
| --- | --- |
| Desktop framework | Electron |
| Language | TypeScript |
| Frontend framework | React |
| Styling | Tailwind CSS |
| Build tool | Vite |
| Packaging | electron-builder |
| Local database | SQLite |
| ORM | Prisma |
| State management | Zustand |
| Charts | Apache ECharts |
| Logging | Pino |
| Testing | Vitest and Playwright |
| Configuration | YAML |
| AI integration | OpenAI API abstraction layer |

## Rules

- This stack is approved for Version 1.0.
- Do not replace any component without explicit CEO approval.
- Do not introduce alternative frameworks during implementation.
- New technology ideas belong to the backlog.
- This task records the decision only.
