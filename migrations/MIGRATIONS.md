# Database migrations

ALIVO OS 1.0.0 uses database schema version **1**. Schema 1 is established by the
application's first-run bootstrap; there are no historical project-controlled
migration steps before schema 1. Future migrations must be added here with
zero-padded names and applied in ascending lexical order. Backup format 1 and
minimum restore version 1.0.0 are supported by this release.
